# 🤖 Ollama AI Chatbot

My second LLM project using Python and Ollama.

This project is a simple AI chatbot that allows users to have a conversation with a local AI model.

## 🚀 Features

- 💬 Chat with AI
- 🤖 Uses Ollama
- 🧠 Uses Gemma 3 1B
- 🔄 Continuous conversation
- 🚪 Type `exit` to quit
- ⏳ Shows "AI is thinking..." while generating a response

## 🛠️ Technologies

- Python
- Ollama
- Gemma 3 1B

## 📚 What I Learned

- Using `ollama.chat()`
- Sending messages to an LLM
- Getting AI responses
- `while` loops
- User input
- Python virtual environments
